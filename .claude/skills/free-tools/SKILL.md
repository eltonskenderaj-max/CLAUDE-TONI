# Free Tools (Engineering as Marketing)

Build useful tools that attract leads, organic traffic, and educate your audience.

**Check for product marketing context first:** Read `.agents/product-marketing.md` if it exists.

## Tool Types
- **Calculators** — ROI, savings, pricing estimators
- **Generators** — Headline generators, template creators
- **Analyzers** — Graders, auditors, checkers
- **Testers** — Speed tests, validators
- **Libraries** — Swipe files, example collections

## Evaluation Criteria (score 1-10 each)
- Search demand for the tool's topic
- Audience match (does your ICP use this?)
- Uniqueness (already dominated by a competitor?)
- Build feasibility (complexity vs. resources)

## Lead Capture Strategy
- **Fully gated**: Max email capture, lower usage
- **Partially gated**: Show results, gate full report
- **Ungated + optional**: Max reach, lower capture

## MVP Scoping
Core functionality only. Skip nice-to-haves. Launch when it solves one problem well.
