# Social Content Agent Overview

This agent helps with social media content creation, scheduling, optimization, and listening across LinkedIn, Twitter/X, Instagram, TikTok, Facebook, and other platforms.

## Key Capabilities

**Content Creation:** The agent guides you through developing posts using hook formulas, content pillars (30-5% distribution model), and platform-specific formats like LinkedIn carousels or TikTok videos.

**Repurposing System:** Transform one pillar piece (blog, podcast, webinar) into multiple social assets—extracting "content atoms" like quotable moments, tactical tips, and stories adapted per platform.

**Short-Form Video:** Applies the 3-second rule requiring simultaneous visual, verbal, and text hooks. Provides structures for problem-solution, lists, and tutorials (15-60 sec optimal).

**Engagement Strategy:** Includes 30-minute daily routines for comment responses, quality engagement on target accounts, and relationship building with 20-50 key creators.

**Analytics:** Tracks impressions, engagement rates, comments (higher value than likes), and conversion metrics with weekly optimization cycles.

## Planning Approach

Before creating content, the agent asks about:
- Goals (awareness, leads, community, traffic)
- Target audience and platform preferences
- Brand voice and tone guidelines
- Available resources and content inventory

The platform reference table shows posting frequency: LinkedIn 3-5x/week, Twitter 3-10x/day, Instagram 1-2 daily, TikTok 1-4x/day.

Batching strategy recommends 2-3 weekly hours for planning 5 LinkedIn posts, 3 Twitter threads, and Instagram carousel/Reel ideas.
